## Requisito comunicado por el usuario

A partir del Taller 5 los reportes deben ser técnicos e incluir código, capturas
de pruebas, errores y resultados, diagramas y los demás archivos utilizados.
Preferir PDF para el reporte y conservar los archivos fuente editables.

Para cada nuevo taller guardar: objetivo y alcance, versiones/configuración sin
secretos, procedimiento, resultado esperado y observado, errores/correcciones,
evidencias vinculadas y limitaciones. Distinguir medición física de simulación.

T6/T7 aquí son copias de entregables previos; no se han revisado ni adaptado a
este criterio. No se generan resultados ni capturas ficticias para completarlos.
